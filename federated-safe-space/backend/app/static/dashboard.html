What is this?

A reference platform where a content-moderation model is trained across many devices with federated learning — raw text never leaves the device; only compressed, masked, DP-noised model updates do.

Data flow

1. Client pulls the global model when online → 2. trains locally on consented data → 3. clips, top-k compresses, quantizes, masks the update → 4. uploads (residual errors carry over across disconnects) → 5. server aggregates a quorum with DP noise → 6. new global model version is published.

Demo status

Protocol mechanics are real. Moderation scoring is a keyword placeholder until the federated model plugs in; simulated clients (docker compose client-sim) send synthetic updates so you can watch rounds aggregate live.
